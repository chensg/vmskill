# 《画出地底的人》讲述稿 v1

- **一句话**：1815 年，一个铁匠的儿子画出了世界上第一张全国地质图。四年后他进了债务人监狱，而看不起他的学会拿他的成果印了一张更便宜的地图。
- **子型**：历史小故事片，因果型（骨架：钩子 → 正题 → 反转 → 回升 → 尾板）
- **版式**：**竖版 Short** 1080×1920，`HARD_LIMIT = 180`（YouTube Shorts 上限）
- **规模**：16 镜 / 25 条旁白 / 约 417 字
- **片长估算**：按 4.6 字/秒约 119s，按以往实测 4.3 字/秒约 126s，离 180s 上限还有 50 多秒。以门禁二实测为准
- **素材**：`IMG_SOURCE = "found"`。16 镜里 13 镜是 19 世纪的公版原件，**不生成任何人脸**
- **拥挤度**：英文中低，中文低（见选题记录）。**中文视频平台还要人工在站内搜一次**
- **状态**：等门禁一（讲述稿人工确认）
