# 逐项检查表

开工到交付走一遍。每条后面括号里是踩过的坑，不是理论。

## 开工前

- [ ] 版式定了：竖版 1080×1920 还是横版 1920×1080（字幕布局和运镜方向都不同，不能事后互换）
- [ ] **画种定了**，并且知道它连带反转哪几处（字幕极性 / 调色方向 / 出图要留白还是留暗）
      （题材苍茫用水墨，富丽写人写花用工笔重彩，**叙事强、核心是人脸用电影写实**）
- [ ] 有无诵读定了（决定时间轴由"读得完"排还是由语音落点排）
- [ ] 图文是否强相关定了（决定选图标准）
- [ ] **三条轴定了，而且是问过用户的**（都别默默用默认值）：
      - `MOTION` 运镜还是静帧（可逐镜覆盖）→ 连带素材门槛、每镜停留、粒子层的价值
      - `MUSIC_MODE` 生成 / 公版 / 不要 → 连带片长怎么排、归一化策略、要不要附授权
      - `IMG_SOURCE` 按任务书生成 / 自己找 → 连带**分镜跟着图走还是图跟着分镜走**
- [ ] **片长是从配乐封顶倒推的**（仅 `MUSIC_MODE='generated'`）：
      mureka 实测 180~245s 随机，按最坏的 180s 算，
      片长控制在 135~145s 才有 40~60s 切入余地
      （《再别康桥》164.8s 对 179.9s 只剩 15.1s，怎么挪都有落点撞进谷里）
      公版录音通常远长于片长，这条不适用；不要配乐时更不适用
- [ ] 楷体字体文件（simkai.ttf）在脚本能找到的位置
- [ ] **确认过这个会话有没有图像生成工具**。多半没有（只有 music/video/voice/sound），
      那就早点写好自包含的图片生成任务书交给用户
- [ ] 配乐/音效生成后的**下载要用户的登录会话**（Agent 直接取实测 401），一并提前说

## 时间轴（先跑 `check`，通过了再碰素材）

- [ ] 每条正文停留 ≥ 字数 × 0.45 + 1.8 秒（七言 ≥ 4.95 秒）
- [ ] 每镜时长 ≥ 可读下限 + 进来的转场 + 出去的转场 + 0.8 秒呼吸
- [ ] 两列用 `|` 分隔，**不是逗号**（句内有该上屏的标点时逗号法会把它们吃掉）
- [ ] 左列延后这一句时长的 28%~30% 出现，两列一起留到句末
- [ ] 四言两句一组拆两列，可读下限按含标点九字算 = 5.85 秒
- [ ] 没有转场压在字幕上（转场要落在两句之间的气口）
- [ ] 转场时长**不是一个常数**：上下阕之间 2.0~2.5s，特写之间 0.6s，
      一问一答 0.8s，末镜转诗文页 2.5s，其余 1.2s
- [ ] 转场时长都合法（> 0 且短于相邻镜头）
- [ ] 诗文页字块在诗文页镜头起点之后，且**在片尾淡出开始之前就出全**
- [ ] 运镜行程检查通过：走 d 的行程需 z ≥ 1/(1-d)
      （20%→1.25，30%→1.43，40%→1.67。这条一个系列里拦下过十一镜）
- [ ] 慢推镜的起幅 z 别太小：z=1.12 时焦点只能落在 [0.446,0.554]
- [ ] **运动方式和参数对得上**，且**回归自测报警了**（三条都要报）：
      有行程的镜标成 `static` / 原地不动的镜标成 `kenburns` / `motion` 写错字
      （静帧必须**显式**声明——允许"z 起止写成一样"隐式表示的话，
      "写了位移没给足缩放"那个最贵的 bug 就变成合法配置，check 再也拦不住）
- [ ] **平台安全区检查通过**，而且**回归自测报警了**
      （把字幕放回旧位置 `SUB_TOP=700` 必须报警。第一版参数顺序写错，
      检查在确实撞了的位置上一声不吭——永远不报警的检查比没有检查更糟）
- [ ] `SUB_TOP` 按最长一列反算：`SUB_TOP + 最长列字数 × 字号 ≤ 864`
      （7 字→420，8 字→290，9 字→270）
- [ ] 诗文页竖排时整块列心左移，右起第一列不进操作栏（1080 画心 540，八列只能到 500）
- [ ] 音乐够长：切入点 + 片长 ≤ 全曲长度
- [ ] 音效互不重叠、每条都写死了播放长度、都在片长内

## 素材

- [ ] **出图之前跑过 `budget`**，出图任务书里的尺寸是它算出来的分档，
      **不是一律 4K**（统一 2896 实测比按镜要多花 60%~63% 的像素）
- [ ] 每镜 pp = 裁后有效短边 / 本镜最大 z / 1080：
      静帧 ≥ 1.00（恒等重采样）/ 运镜 ≥ 1.20（实测 98%）/ 细节镜 ≥ 1.30
      （**pp < 1.0 = 在放大，check 会拦**；1.0~目标之间只提示）
- [ ] 没有哪一镜被 PREP 卡住（需要 > 2160）——那是流水线天花板，
      买更大的图补不回来，只能降 z / 改静帧 / 抬 PREP
- [ ] 生成器出不了 9:16 时，尺寸**除过裁切损失**（出 2:3 裁 9:16 只剩 84%）
- [ ] 自己找的图：**拿的是原始档不是网页派生图**（详情页大图常常已被缩到 1000px 级）
- [ ] 自己找的图：**每张都登记了 `CREDITS` 五项**（作品/权利人/来源/授权/链接），
      并跑过 `credits` 导出素材来源表
      （"公有领域"是对**作品**说的，不一定对**这一张翻拍**成立）
- [ ] 每张都**打开看过**；十张以上先拼联络表核对序号，**联络表要带调色**
      （靠读缩略图编号选图，九张里错过三张）
- [ ] 字幕区**按画种要对的东西**：纸本要留白，**暗调写实要留暗**
      （留白事后还能压，留暗不行）
- [ ] 字幕区是**整条**从头到尾干净，不只某一段（摇镜会把字幕拖过明暗分界）
- [ ] 写实版：暗区给的是**精确矩形**且列清了"不能有什么"；
      横移那一镜的暗区更宽；月亮放画面左侧；诗文页底整张都暗；封面上方三分之一空
- [ ] 两列时字幕带更宽：竖版实测占画宽 76%~93%。生成时就得提，事后没法补救
- [ ] 没有自带文字、印章、签名、水印、匾额、招幌
- [ ] 用了同一段共用风格前缀，且**先出过两张样图**（情绪核心那张 + 最难的那张）
- [ ] 后续每张都把第一张样图当参考图传进去（有反复出现的角色时是硬性的）

## prep 之后（先看 `probe`，**再跑 `trace`**）

- [ ] **调色是量了直方图之后定的**，不是按画种套
      （写实版生成结果常常欠曝：平均 15、中位数 8、最亮 133；
      照抄纸本那句 contrast=1.06 会把中位数压成 0）
- [ ] 量的是 `mean / p50 / p90 / p99 / max` 和"亮度 <16 的面积占比"
- [ ] 图库实拍：重手统一了白平衡/反差/饱和
- [ ] **跑过 `trace`**，两项都过：
      - 每条字幕**实走轨迹**上的底离字色 ≥ 50 级（用分位数，不用绝对极值）
      - 每一镜**落幅那一帧**的整帧极差 ≥ 25、平坦行没超标
- [ ] `probe` 的报警**不要直接采信**——它量整张图，镜头只经过其中一段，
      两类报警都会误报，以 `trace` 为准
      （曾报"最暗 75"，实际字幕走在 149~193；《清平调》报右侧被披帛占了，
      实际字幕够不到。**这两次只信 `probe` 都会换掉本来没问题的图**）
- [ ] `trace` 的平坦行报警也要复核：漆黑室内大多数行本来就是均匀的黑，
      而平坦行抓不到缩放。**抽这一镜首尾帧比一比再下结论**（《雨霖铃》镜 11 是误报）
- [ ] 不要因为"这张看着亮/浓"就先入为主翻极性
      （《清平调》十五张重彩实测 197~226 零告警，`FLIP_SHOTS` 全程为空）

## 粒子层（如果做）

- [ ] `fx` 跑完**方向自验通过**：雨/叶位移为正 = 往下
- [ ] **拿旧的有 bug 的文件回归验过**这个检查真的会报警
      （雨往上飘这个错在系列里活了两支，因为静帧上看不出来——
      单帧雨丝是一道竖线、没有方向，正好是目视验证的盲区）
- [ ] 在成片上复验时用的是**带符号帧差**，不是绝对值帧差
      （绝对值差会让相关峰恒定落在 0，看起来像"根本没在动"）
- [ ] 起点落在对的镜头里（星辉起点早 1.6 秒，星星就浮在大白天的河面上）
- [ ] 叠加层真的会结束：纯色源给定长 `d=`、`alphamerge` 加
      `shortest=1:repeatlast=0`、`overlay` 加 `eof_action=pass:repeatlast=0`
      （只加 `eof_action` 没用；落叶曾从第 20 秒起冻在画面上挂到片尾）
- [ ] 粒子层叠在 scrim **之前**（反过来会把粒子一起压掉一档）

## 渲染

- [ ] 改了字幕只跑 `c`（a/b 两趟不含任何文字和声音，重渲是纯浪费）
- [ ] 改粒子颜色/浓度/方向只跑 `fx` + `c`
- [ ] 换图或改调色要从 `prep` 重跑
- [ ] 纸本画面：`pass_a` **不加 vignette**、`pass_c` 不加颗粒、淡入淡出用**白场**
      （纸自己有纹理，叠上去就是脏）
- [ ] 暗调写实：vignette 和轻微颗粒**要加**，淡入淡出用**黑场**

## 渲染之后：`motion`

- [ ] 跑过 `motion`，**两个方向都对**：运镜镜均差 ≥ 4.0，静帧镜均差 ≤ 0.6
      （实测参照：静帧 0.1，运镜 37.7）
- [ ] 没有"没量到"的镜头——**读不出帧不算通过**
      （第一版跳过之后照样打印"全部都看得出来"，又造了一个不会报警的检查）

## 音乐与音效

> 下面前七条只对 `MUSIC_MODE='generated'` 成立。
> 公版（`public_domain`）和不要配乐（`none`）见 `references/music.md`，
> 关键差别：**录音权 ≠ 作品权**、拿到之后要跑 `mquality`、
> 只剩音效时**不做响度归一**。

- [ ] 提示词里争取了时长（≥ 片长 × 2.5），并把"全程不许稀疏"列为最高优先级
      （但**别指望它**——试过三轮，写死"至少 4 分 30 秒"照样拿回 193.4s。
      mureka 提示词上限 1024 字符，超了校验阶段退回不消耗额度）
- [ ] 用 `ebur128` 量过整首的响度曲线
- [ ] 切入点是用 **maximin** 选的，不是加权和
      （加权和会把开场分拉满、却把成片中点和末句推进最弱处，栽过一次）
- [ ] 打分窗口覆盖了：情绪核心 / 每段收尾长留 / 成片中点 / 末句 / 诗文页 / 片尾淡出
      （**开场可以故意不放进去**——片头六七秒只有标题，弱一点反而合适）
- [ ] **把全曲 < −25 LUFS 的低谷段列出来看过**，确认选出的窗口避开了它们，
      并区分"中段 breakdown"和"结尾的自然收尾"
      （《雨霖铃》最低 −70.6 在 191~193s，那只是收尾；《再别康桥》候选 A
      在 121~130s 藏了 1.7s 近乎静音，只能弃用）
- [ ] **别盲发第二条候选**，先量，量出有中段 breakdown 再发
- [ ] 淡入收在 1 秒以内（长淡入叠在弱前奏上，开头七八秒会近乎静音）
- [ ] 音效**先查过内置库**（只有 35 条 UI/转场类，没有自然环境声，但要先查）
- [ ] 音效增益写的是**目标响度**，由脚本按实测反算，不是写死 dB
      （五条生成音效实测跨度 45 dB，写死增益不可能对，且错了看不出来）
- [ ] 每条音效**写死了播放长度**，生成长度比播放长度长（不循环 = 没有接缝）
      （18 秒的秋风把后面的雁鸣整个埋掉，而混音本身是"成功"的）
- [ ] 可疑的音效**分频段量过** `<120Hz / 120–2k / >2kHz`
      （−53.5 LUFS 的江风不是失败，是能量全在 120Hz 以下、K 加权量得低，
      但手机喇叭放不出来。**LUFS 判不出这种情况**）
      （ElevenLabs SFX 提示词上限 450 字符）
- [ ] 音色好坏**量不出来**，把最终选择权交回给用户
- [ ] 公版录音：跑过 `mquality`，四项看过（底噪 / 带宽 / 声道 / 头尾静音），
      `MUSIC_CREDIT` 五项填全，切入点**听过首尾**（乐句边界量不出来）
- [ ] 不要配乐：确认过归一化走的是对的分支
      （有旁白 → 照常归一；只剩音效 → **不归一**；什么都没有 → **不出音轨**）

## 交付前

- [ ] 跑过 `still`，**逐张打开看过**字幕认不认得出
      （`-ss` 放在 `-i` 前会让抽出来的帧一个字都没有，脚本已规避）
- [ ] 小字单独放大看过：片头标题、诗文页正文和落款
- [ ] 跑过 `measure`，字幕底离字色至少差 50 级
      （**只能量无字的 master.mp4**。在烧了字的预览上量，量到的是字本身，
      每条会整整齐齐报同一个数，看起来条条危险，其实一条都没问题——骗过一次）
- [ ] **把 `measure` 和 `trace` 逐条对一遍**，应该只差几级、且都判同一句最差
- [ ] **对不上时先确认 `pass_a` 里有没有 `trace` 没建模的滤镜**，再怀疑运镜
      （《雨霖铃》差 5~31 级看着像运镜出错，实际是 trace 少算了 vignette：
      关掉 vignette 重渲同一帧量到 119，trace 报 118。
      模板里 `vig_factor()` 已补上）
- [ ] 封面打开看过：标题没压在人脸、窗框或其他主体上
      （曾有一版落款正压在人的头顶上）
- [ ] 成片规格核对：分辨率、帧率、H.264 + AAC 48k、响度 −15 LUFS 上下
- [ ] 封面用 `-disposition:v:1 attached_pic` 嵌进 mp4 做封面帧，**并且 remux 之后再核一次**
      （`c` 会覆盖成片文件，重渲之后封面帧会掉，要重新嵌）
- [ ] 用户没要求的事没有顺手做（比如没让删的旧版本不要删）

## 交付时要主动说的

- **三条轴的取值**：运镜还是静帧（混用的话哪几镜）、配乐是生成/公版/没有、
  图是生成的还是找来的。**"没有背景音乐"和"完全没有音轨"尤其要说**——
  它们看起来像做漏了
- 用了找来的素材时，**素材来源表跟着成片一起交**（CC-BY 的署名要跟着片子走）
- 哪几处是妥协的（素材达不到、音效在手机上会很轻、图文对应牵强）
- 哪几处做了跟原计划不同的决定，以及为什么
- 还留了什么可以改的口子（换某一张图只需要重跑哪几趟）
