# 渲染四趟、命令一览、中间件对账

> 2026-11-11 从 SKILL.md 原样挪来（总纲只留摘要）。

## 渲染分四趟，改什么跑哪趟

| 趟 | 做什么 | 什么时候要重跑 |
|---|---|---|
| `prep` | 裁切 + 统一调色 → img01..N，并自动 `probe` | 换图、改调色、改裁切位 |
| `a` | 每张图做 Ken Burns（+ vignette）**或按 `MOTION` 出静帧** → shots/ | 改运镜、改 `MOTION` 或改了 prep |
| `b` | xfade 溶解转场串成无字无声的 master.mp4 | 改镜头时长、转场或改了 a |
| `c` | 粒子 + 混音 + 归一 + 烧字幕 → 成片 | 改字幕、scrim、音乐、音效、粒子颜色 |

外加十一个验证/工具命令：`check`（永远先跑它）、
`budget`（**出图之前**，按每镜的运动反推要多大的图，分档抄进任务书）、
`trace`（缺图会跳过，出一张验一张）、
`pixels`（**出图之后**，1:1 原始像素贴片联系表，看素材有没有真细节）、
`motion`（**跑在 `a` 之后**，量每镜首尾帧差；运镜镜要看得出动，静帧镜要真的不动）、
`fx`（生成粒子层，自带方向自验）、`pick`（maximin 选音乐切入点，并自动列低谷）、
`mquality`（**公版配乐必跑**，量底噪/带宽/声道/头尾静音）、
`credits`（导出素材来源表，用了找来的素材时是交付物）、
`still`（烧预览抽静帧，用眼睛看）、`measure`（量字幕底，用数字验）。

出图之后的三道，缺一道就会漏掉一类问题：
`check`（有效分辨率，**要先填 `SRC_NATIVE`**）→ `trace`（字幕底与落幅）→ `pixels`（真细节）。

**改了字幕只跑 `c`**——a/b 两趟不含任何文字和声音，重渲是纯浪费。
**改粒子颜色/浓度/方向只跑 `fx` + `c`。**

讲述模式多一趟 `sync`（量旁白实测时长→推整条时间轴），**排在 `check` 前面**；
而且它的 `SHOTS` 不写 `dur`，改了旁白或气口之后要从 `a` 重跑（每镜时长变了）。

### 讲述模式的中间件对账（`make_story_h.py` / `make_story_v.py`）

`prep` 每出一张 imgNN、`a` 每出一个 shotNN 都记一笔「按什么输入做的」
（`prep_keys.json`、`shots/shotNN.key`），下游用之前先对账，对不上就停：

- **`a` 只补过期的镜**，默认多路并行（`JOBS` = 核数−1，上限 5）。`a 1` 串行看进度，
  `a force` 全部重渲。所以"改了什么跑哪趟"不用再自己算 —— 改完跑 `a`，它自己知道补哪几镜。
- **`a` 拒绝开渲**：imgNN 不是按现在的 `CLIPS` 做的（插过镜、改过裁切/调色、换过图、
  prep 那一镜缺图跳过了）。以前这是"插入点之后整体错一格、每镜单看都正常"。
- **`b` 拒绝拼**：shot 没渲、渲到一半被打断（残文件）、参数或镜长变了没重跑 `a`。
- **不带参数不再等于 `all`**，只打印用法。`all` 要明说。
- `credits` 重写 `素材来源.md` 前会先对指纹，被手改过的**先备份成 `.bak-时间戳`**。
  手写的处理说明仍然另立一份（`素材处理说明.md`）。
- 交付物目录看起来像片库根（底下有两个以上带 `素材/` 或 `build/` 的子目录）时直接停 ——
  脚本错放在项目根、`../素材` 又恰好存在（`ani/素材/` 就是）时，`..` 就是 `ani/`。

回归：`python tests/test_intermediates.py`（仓库根，逐条把被检查的东西弄坏、验它报警）。
