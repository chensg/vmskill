# 小说第一人称片（讲述模式的子型）

> 2026-11-11 从 `storytelling.md` 第九节原样挪出（节内小标题不变，别处写的「第九节」指的就是这份）。

## 九、小说第一人称模式：让书里的一个人自己说

> **第一支还没跑完。下面凡是标「待实测」的都不要当数**——它们是按已验过的
> 系数外推的，第一集交付后必须回来换成实测。这一节的其余部分（人称合约、
> 忠实度分级、版权那三条）是设计判断和已知的坑，不依赖实测。

### 它是什么，不是什么

**不是荐书片。** 荐书片站在书外面介绍一本书；这个站在书里面，由一个角色
对着观众把他自己那段经历讲一遍。观众要的不是"这本书好在哪"，是"后来怎么了"。

| | 荐书片（第七节） | **小说第一人称** |
|---|---|---|
| 谁在说话 | 一个读过这本书的人 | **书里的一个人** |
| 观众看完记得的 | 这本书值不值得读 | **这个人后来怎么了** |
| 片长 | 165~185s，一本书一支 | **600s ± 60**，一本书**连载多集** |
| 结构 | 三幕：书与人 / 内容 / 追问 | **一集一个完整的故事** |
| 版式 | 竖版、烧录字幕 | **横版 1920×1080 + 外挂 SRT**（同《经度》） |
| 每镜停留 | 3~8s | **8~15s** |
| 最大的风险 | 把社会议题外挂上去 | **"我"知道得太多**；**抄中译本** |

机件共用讲述模式的全部：旁白驱动时间轴、`sync` 量实测、侧链躲闪、两道门禁、
`make_story_h.py` 分段 + `join.py` 拼接。下面只写不一样的。

### 一、人称合约：四个问题，第一集之前答完，答完不许改

这个形式唯一不可逆的决定，缺一条后面每集都会晃：

1. **谁在讲？**
2. **他在什么时候讲？** 事发当时 / 多年以后 / 临死前。
   **这一条决定他知道多少**，是四条里最容易漏、代价最大的。
3. **他在对谁讲？** 对观众 / 对法官 / 对一个已经死了的人 / 对自己。这一条决定语气。
4. **他为什么现在要讲？** 讲述动机。**全片的能量从这里来**——
   没有动机的第一人称，就是把小说念一遍、换了个人称代词。

**第二条错了会以很难发现的方式毁掉片子**：叙述者顺口说出他当时不可能知道的事。

> 「那时候我还不知道，他已经在楼下等我了。」——合法，"那时候我还不知道"把时点交代了
> 「他已经在楼下等我了。」——**越权**，这一句"我"不在场

**写稿时每一句都要能回答"他是怎么知道的"。** 稿子里把越权句标 `[越权]`，
`check` 判不出来，只能人查——但标出来就查得动，不标就一定漏。

### 二、选谁当"我"：不一定是主角

标准只有一条：**选那个知道得比观众以为的多、又比全知少的人。**

| 选谁 | 好处 | 代价 |
|---|---|---|
| 主角 | 情感最直接 | 常常什么都知道，悬念要另想办法 |
| 旁观者（仆人 / 医生 / 律师 / 后来的人） | 天然有信息差，悬念自己长出来 | 情感隔一层 |
| **被误解的一方** | **最强的一路**：观众带着成见进来，第一句就被推翻 | 要求原著里这个人真有话说，不能硬安 |

### 三、忠实度分级：`CLAIMS` 的机件原样用，三级换掉

故事片的事实分级（史实/概数/假说）防的是"把推断说成史实"。小说是虚构的，
那张表不适用——**但风险没有消失，只是换了地方**：观众会拿这一集当原著转述。

| 级别 | 意思 | 规矩 |
|---|---|---|
| `原著` | 书里明写的 | 正常讲 |
| `暗示` | 书里有依据但没写死 | 可以讲，**不能讲成定论** |
| `我加的` | 原著没有，为讲述而加 | **只许补感官细节和内心，不许改变任何情节结果** |

**「我加的」有三条红线，每条都对应一种真实发生过的错法**（荐书片上踩的，
当时的表现是"大框架全对、细节全错"）：

1. **不许把两个人物揉成一个。** 最常见也最隐蔽——讲述上确实更顺，
   但从此这一集和原著对不上了
2. **不许把两场戏并成一场。** 同上
3. **不许补"似是而非的细节"**（具体日期、服饰、器物、地名）。
   **越具体越要查，查不到就写模糊的。** 大框架不会错，
   错的永远是那些为了让画面好看而补上去的具体东西

真要动情节结果（合并、删角色、改结局），**片尾必须说一句**，不能只写在简介里——
和故事片"假说必须在片内自拆"是同一条规矩，那段代码不用改。

### 四、切集：不按章节切，按"我"的状态切

一集要是一个**完整的故事**，不是一个章节区间。判据一句话：

> **这一集结束时，"我"和开始时还是同一个人吗？** 还是，就没到切点。

每集的骨架（和故事片的钩子→正题→反转→尾板不一样）：

| | 占比 | 干什么 |
|---|---|---|
| 冷开场 | ~5% | 一句话把人钉住。**每集都要换一句，不要有系列口号** |
| 我是谁 | ~5% | 给中途进来的人 8~12s。**每集换一种说法说同一件事**，不复用同一段 |
| 幕一 | ~25% | 这一集的"我"想要什么 |
| 幕二 | ~30% | 挡在中间的是什么 |
| 幕三 | ~30% | 代价，以及"我"变成了谁 |
| 钩子 | ~5% | 下一集。**落在一个问题上，不是一段预告** |

**每集自足**：不看上一集也看得懂，看完这一集也是完整的。做不到就是切点选错了。

### 四之补、下集预告板：**独立一镜、独立一图、不出声**

连载必须给观众一个进下一集的入口。但它和第四条那个「钩子」是**两件不同的东西，
不许互相打架**：

| | 钩子 | 预告板 |
|---|---|---|
| 是什么 | 最后一句**旁白** | 结尾之后的一张**静帧** |
| 落在哪 | 一个问题 | 下一集的名字 + 一句不揭底的话 |
| 有没有声音 | 有（它就是声音） | **没有，一个字都不念** |

**三条规矩，第二条最要紧：**

1. **独立一镜、独立一张图，不要压在结尾那一镜上。**
   最后一镜通常是和镜 1 闭环的那一张，它是本集的收尾画面，要让它自己收完。
2. **不出声。** 最后一句旁白后面那段静**是结尾的一部分**——
   给预告配旁白等于把结尾踩掉，整段会从「一个问题」变成「一段预告片」。
   《白衣女人》第一集最后一句是「是一个日子。」，那句后面必须是静的。
3. **不剧透。** 连载都有一张底牌（本系列是「为什么她们长得像」），
   **预告板一集都不许碰**。挑图也照这条：**没有脸的画面最安全**。

**实现（脚本本来就支持，不用改代码）：**

- `SHOTS` 里加最后一镜，写 `dur=`（`timeline()` 对没有旁白的镜就是读这个），
  `motion="static"`，`xf` 给长溶解（2.5s）
- `ENDCARD = dict(head="下一集 · X", sub="一句话", t0=, t1=, y=)` 压在这一镜上
- 片尾 `FADE_OUT` 自然落在预告板上，正好

**这一张图是本集第二张有留白要求的图**（另一张是压开场标题的那张）。
字幕外挂虽然删掉了留白要求，但**烧进画面的标题和预告板不在豁免之列**，
出图任务书里要给那条横带写死。

**顺带一条切集的经验**：《白衣女人》原定 8 集，写完第一集变成 7 集——
第一集的稿子自然收在了原定属于第二集的材料上，剩下的撑不起一整集。
**这不是排错了，是第四条那个判据在起作用**（一集在「我」的状态变化上收口，
不在章节区间上收口）。**分集表要允许在写稿过程中改**，写死在总谱里的是判据，不是集数。

### 五、片长与镜数（**待实测**）

600s ± 60。**一集 = 一支完整的片子，一次渲出来，不分段。**

`make_story_h.py` 是《经度》的**分段**脚本，但它对单段是通的、而且是干净的：
`SEG_INDEX = SEG_TOTAL = 1` → `SEG_FIRST` / `SEG_LAST` 同时为真 →
开场淡入、片尾淡出、标题字卡、尾板、假说自拆检查**全部自动打开**，
`*_预览.mp4`（归一 + 头尾淡场）就是交付物，**不用跑 `join.py`**。

**为什么第一支不分幕**（这一条改过一次，记下来免得来回摇）：
`join.py` 和分段制度整套是**为接缝服务的**——逐段归一的响度台阶、
每隔几分钟黑一次、段长不是整帧的 A/V 漂移、SRT 偏移。
**一集就是一支完整的片子时，一个接缝都没有**，那套机件全部空转。
分段剩下的唯一好处是「改一幕只重渲一幕」，而那是**推测的**迭代成本，没有实测。
所以第一支按单段跑，**跑完记下四趟渲染各自的实测耗时**，再决定要不要分。

（分段仍然是对的，当一集真的长到不得不分、或者几集要拼成一支合集的时候。）

排片长系数：**先按 0.36 秒/汉字排**。依据是荐书片默认节奏实测 0.346，
第一人称的气口比转述多（见第七条"该停的地方停住"），所以往上估一点。

> 600s ≈ **1600~1700 汉字/集**。第一集跑完必须回来把这个数换成实测。

镜数 **45~60 镜/集，每镜 8~15s**——比故事片（3~8s）慢一倍，理由见下一条。
**出图额度不是 45~60 张**：「同一张图不同取景窗」那个杠杆在这里比荐书片还划算
（一段回忆本来就该停在同一个地方），实际出图 **25~35 张/集**。

### 六、画面：静帧/缓动不是省钱，是这个形式的正解

第一人称是**记忆**，记忆是静止的画面加上一个声音。画面一动，
观众就从"听他回忆"掉回"看一段影片"。所以：

- `MOTION` 默认 **`static`**，缓动是**逐镜覆盖的例外**，不是默认。
  和其余所有模式相反（那些默认 `kenburns`）
- 要动的那几镜，行程压得比故事片更小：故事片 Ken Burns 门槛 pp ≥ 1.20，
  这里的"缓动"档**待实测**，先按 **z 行程 1.04~1.08、镜长 ≥ 10s** 排
- 转场**以长溶解为主（1.5~2.5s）**，硬切留给"我"被打断的地方——
  和故事片正好相反（那边硬切是常态、长溶解全片一两处）

### 七、声音：全片最大的一处改动，**不要照抄第八节**

第八节那套（渊博小叔 / storytelling / scale 3）是**讲述者**的声音——
一个读过资料的人在给你讲。第一人称要的是**角色**的声音，一个人在说自己的事。
照抄会得到"一个纪录片旁白假装自己是主角"，比 AI 味更难受，因为它每一句都对。

| | 讲述模式 | **第一人称** |
|---|---|---|
| `voiceId` | 渊博小叔 | **试听选，像画种一样不可逆，不要替用户定** |
| `emotionScale` | 3 | **4**（说自己的事该更有情绪）。**5 仍然是"演"** |
| `speedRatio` | 不给 | **同样不给**，理由一样。要快要慢**从 `performancePrompt` 里要** |
| 目标语速 | 实测 4.0~4.5 | **比历史基准快 5%**：基准 4.20 → **目标约 4.40 字/秒** |

**语速快 5% 的正确做法是砍指示，不是调参。** 先把逐句 `performancePrompt` 里的
「略停」「吊住」「等下一句落下来」这类指示删掉一批（只留真正的转折句和落点），
**不要去动 `speedRatio`**——变速是整条等比拉伸，句子内部该快的地方也快了，
听感立刻变回"念"。砍指示要来的快是**有轻重的快**。
连带：句间静默也跟着少，所以**整片时长的降幅大于 5%**（语音只占全片约六成，
但砍掉的静默是净减），排片时按 **秒/汉字系数 × 0.95** 估，跑完实测覆盖。
| `performancePrompt` 底子 | 「像讲一个真实的旧故事…」 | **整条重写**，见下 |
| **句尾略收不上扬** | 有 | **原样保留**。它挡的是 AI 味，和人称无关 |

底子改成（**待实测**）：

```
像一个人在对着一个人说自己的事，不是在讲故事；句尾略收不上扬；
该停的地方停住，不要赶；克制，越难过的地方越不要用力。
```

最后一句是这个形式独有的。**第一人称最容易翻的车是"读得太投入"**：
角色在讲自己最痛的一段，TTS 一用力就变成朗诵比赛。
「越难过的地方越不要用力」必须写进**底子**，不能只逐句加写——
因为难过的地方不止十来句。

**声音试听是一道门禁，和画种同级。** 挑这一集里**最难的一段**、30s 左右，
用 2~3 个 `voiceId` 各出一条交用户听。最难的一段 = 情绪最重、或专名最多的那一段。
**拿最好听的一段去试听等于没试。**

### 八、版权：三条硬规矩，第三条极容易踩

1. **只用公版原著**（作者逝世满 70 年），而且**核对到具体年份**，
   不要"应该是公版吧"。
2. **不抄任何中译本。** 从原文自己读、自己写。这是这个形式最容易犯、
   后果最重的一条——**中译本是有版权的独立作品**，抄了就是侵权，
   "只是参考了措辞"在法律上不成立。**手边不要放译本，放了就会渗进来。**
   原文引用最多一次、15 字以内、自己译、注明出处。
3. **影视形象不是公版。原著公版 ≠ 那个角色长什么样是公版。**
   最典型的：**弗兰肯斯坦的怪物那个平顶头加脖子上两颗螺栓，
   是 1931 年环球影业的美术设计，至今在版权内**——小说 1818 年早已公版，
   形象不公版。**出图任务书里必须明写禁止**，否则生成器一定会给你那个形象
   （它训练数据里全是）。同类的坑：福尔摩斯的猎鹿帽（是插画师 Sidney Paget 的）、
   各版电影海报与剧照、书封。

片尾固定一行：`改编自《原著名》（作者，年份，公版）。中文文本为本片原创。`

### 九、连载合约：《全集总谱》

一本书多集，**跨集不一致比单片翻车更难发现**——每一集单看都对。
所以开一份《全集总谱》，位置和作用同《经度》的《全片总谱》：**唯一真相来源**。
必须写进去、各集脚本从这里读的量：

- 人称合约那四条（谁 / 何时 / 对谁 / 为什么）
- `voiceId` 与 `performancePrompt` 底子
- 画种 + `GRADE`
- **忠实度分级表（全书的，不是本集的）**——和《经度》的 `CLAIMS` 一样，
  某条"我加的"可能第二集埋、第五集才说明，所以自拆检查只在最后一集跑
- 每集的切点，和"我"在这一集里的状态变化
- 片头片尾的固定件（标题版式、版权行）
- **各集实测表**：汉字数 / 语音时长 / 成片时长 / 实测语速。
  这张表是下一集排片长的唯一依据，比任何系数都准
