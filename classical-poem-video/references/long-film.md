# 横版长片：`film.py` 这条路

十几分钟到半小时的横版长片，画面是「生成影片 + 静帧慢推 + 外部照片 / 档案页 / 地图」混着来的，
不走讲述引擎，走 `film.py`：一个脚本从讲述稿和旁白直接排时间轴、合成全片。
规矩（分章、章节卡、不对观众说话）见 `format-long-chapters.md`，这份只讲怎么做出来。

`film.py` 是从《剩人》和《拙政園的山茶》收上来的。那两支每支各抄一套合成脚本（门禁二片、分部预览、正式版、英文轨，
加起来六十多 KB），差别只有十来个常数和一张外部素材表。现在常数和表放进 `build/film_config.py`，流程只此一份。

## 开片

```bash
python episode.py new <项目目录> --type long --title 片名
```

铺出来的东西：

| 文件（都在 `build/`） | 干什么 | 要不要改 |
|---|---|---|
| `film.py` | 合成：门禁二片、分部预览、全片、英文轨 | 不改 |
| `film_config.py` | 这一支的常数和外部素材表 | **填** |
| `vid_prompts.py` | 影片镜的动作提示词 | **填** |
| `music_prompts.py` | 各段配乐的描述和秒数 | **填** |
| `run_pika.py` + `pika_seedvr2.py` + `comfy/` | 本机 Pika 8 步 HD → SeedVR2 1080p，逐条跑 | 不改 |
| `mm_music.py` | 本机 MiniMax Music3 出纯音乐 | 不改 |
| `frame_strips.py` | 影片抽帧条，拼总表看一眼 | 不改 |
| `sep_vocals.py` | 配乐里有没有人声，出去人声版 | 不改 |
| `fish_en.py` | 英文旁白（Fish，过提亮 EQ） | 不改 |

## 约定

- **讲述稿**：`## 章名` 分章，正文从 `## 冷開場` 到 `## 片名候選`（`BODY` 可改）。
  镜头行写成 `**镜号** [标签] 画面说明`，旁白另起一行。引诗的镜在行尾加 `＋[詩]`，旁白里引号内的诗句会竖排在画面右侧。
- **标签决定画面从哪来**：

  | 标签 | 画面 |
  |---|---|
  | `[生…]` | `素材/影片/<前缀><镜号>.mp4`。一镜多条在 `CLIPS` 里写。短了先放慢（最多 15%）再定格，带原片的环境声 |
  | `[推]` | `素材/生成/S<镜号>.png` 慢推 6% |
  | 其余（`[實]` `[檔＋動畫]` `[動畫]` `[卡]`…） | 查 `SPEC` 和 `CARD_BG`；都没有、又不是只有大字的卡，就是**缺画面** |

- **无旁白的镜是卡**，停 `CARD` 秒（末镜停 `ENDHOLD` 秒）。说明里有「片名卡」的出 `TITLE_BIG`，有「章節卡」的出章名；
  带旁白的 `[卡]` 镜说明里写「字卡」和「引号里的字」，就把那几个字打在正中。
- **旁白表** `<项目>/vo_lines.json`：`[{"id": "VO_001", "shot": "01", "txt": 全句, "subs": [分好的字幕句…]}]`，
  音频在 `build/vo/<id>.mp3`。时间轴归中文旁白，镜间留 `GAP` 秒。
- **配乐** `素材/配乐/MM_段N_k.mp3`。部分 1＝冷开场＋第一章，部分 N＝第 N 章。每段把候选接起来，不够长就循环，
  段间 3 秒交叉，被旁白侧链压。
- **分部**：`part N` 和配乐的「段 N」是同一个划分。

## 流程

```bash
python film.py check            # 逐镜报画面从哪来，缺的标 !!；各段配乐几条；章节时间码。不渲染
python film.py tsv              # build/_shots.tsv：镜号、标签、秒数、章、说明、旁白 —— 写提示词、算帧数用
python film.py gate2            # 门禁二片 → 门禁二/：深底「看稿」画面 + 旁白 + 配乐 + 烧录字幕，交给用户听
python vid_prompts.py           # 影片镜清单 + 估时
python run_pika.py              # 逐条出影片（用 runlog.py 起；已有成品跳过）
python frame_strips.py          # 抽帧条，看有没有硬切、人变了、倒着走
python film.py shots 05 37 116  # 调参：只渲这几镜 → 成片/_tmp_final/_check_<镜号>.mp4
python film.py part 2           # 第 2 部分预览
python film.py final            # 全片 → 成片/<NAME>.mp4 + .srt + _章节时间码.txt
python film.py en check         # 英文逐条对槽：超出槽 ×1.06 的要改稿
python film.py en               # <NAME>_音轨_eng.m4a + .en.srt + 英文章节时间码
python episode.py deliver <项目目录>
```

- 在 `build/` 里跑不用带参数；在别处跑加 `--proj <项目目录>`。`--out` 可以把成片写到别处（试渲的时候用）。
- 各镜渲好的成品在 `成片/_tmp_final/`，**比配置和它用到的所有源文件都新才沿用**。换了一张图、重出了一条影片，只重渲那一镜。
- `final` / `part` 遇到缺画面的镜会停。确实要先看个大概，加 `--allow-missing`，缺的用深底顶。
- 改了字幕切法、章名，不用重渲：`python film.py srt`。

## `film_config.py`

普通的 Python 文件，可以用 `os` 和 `PROJ`（项目目录），可以自己定义小函数拼路径。铺下来的那份带全部键和每种镜的例子。
坐标都是**原图的比例**；框写成 `(中心x, 中心y, 宽)`，高按 16:9 自动算。

| `SPEC` 里的类型 | 写法 | 出来的画面 |
|---|---|---|
| `kb` | `("kb", 图, 起框, 止框)` | 照片慢推 / 慢移 |
| `page` | `("page", 图, (x0,y0,x1,y1), [(x0,y0,x1,y1, 进度), …], 底亮度=0.55)` | 档案页放进深底、染成纸色，字行按进度依次点亮，同时慢推 |
| `route` | `("route", 图, 起框, 止框, [点…], {点序号: 地名}, 要不要回程)` | 地图上红线一段段画出来，画到了才出地名 |
| `labels` | `("labels", 图, 起框, 止框, [((x,y), 名字), …])` | 地图上依次亮出地名；`LABEL_NOTE` 给右下角的出处角注 |
| `clips` | `("clips", [影片…])`，一条可以写成 `(路径, 起点秒, 取几秒)` | 外部影片接起来；整支下载的只取一段 |
| `seq` | `("seq", [上面任意几个…])` | 先图后影片这类组合 |

`CARD_BG` 是卡的底图，写法同上，画面压暗到 `DIM_CARD`。

- **`page` 的取景框四边要比字多留 6%。** 画面会朝点亮的那几行慢推，推到头只剩取景框的 94%；
  点亮的字贴着框边就会被切掉（《拙政園的山茶》镜 99 第一版切掉了「閨」字）。坐标用带网格的图读，别估。
- **`MUTE_EXT = True`**：外部影片（`SPEC` / `CARD_BG` 里的 `clips`）不带原声。新闻素材、游记带解说和配乐时用；
  缺省 `False`，生成影片的环境声不受影响。
- `check` 会核 `SPEC` / `CARD_BG` 里每个源文件在不在，路径写错当场报，不用等渲到那一镜。
- 引文板（深底排一段引文）还没有这个类型；先用 `page` 把原页压暗当底纹（点亮列表给空的 `[]`）。

## 三件写进脚本里的事

1. **画面按帧网格对齐，不漂。** 每镜的帧数取 `round(止 × 24) − round(起 × 24)`，而不是各镜自己取整。
   《剩人》正式版就是后一种：一百一十八镜累积下来，画面比旁白晚了 1.48 秒，第五章的章节卡大字压在上一镜的尾巴上。
2. **整片响度归一到 −15 LUFS**（`FINAL_LUFS`）。混完量一次，加一个固定增益，不是动态的 `loudnorm`。
   《剩人》按旁白 −16 做、没有这一步，整片 −16.2。
3. **缺画面要拦。** 原来的脚本缺了画面只打印一行 `!! 没有画面`，然后用深底渲出去。

## 验证过什么，没验证过什么

- `film.py` 用《剩人》的数据复现过：片长 1127.2 秒一致，中文 SRT 和章节时间码与已交付的**逐字节相同**；
  抽了十镜（照片慢推、档案页、路线图、地名、静帧慢推、生成影片、组合、外部影片、卡底），帧数相同的八镜与原片的单镜成品
  **逐帧完全一致**，另两镜因为帧网格对齐差一帧。回归测试 `tests/test_film.py`。
- 《拙政園的山茶》（2026-11-12）：`srt` 出的中文 SRT 和章节时间码与原 `门禁二/render.py` 交付的**逐字节相同**；
  第 1 部分预览（冷开场＋第一章，227 秒）和 17 个外部素材镜渲过、抽帧看过。
- **没验证的**：`run_pika.py`、`pika_seedvr2.py`、`mm_music.py` 只改了路径（工作流改从技能的 `comfy/` 找，找不到退回原位置），
  收进来的时候显卡正在跑别的任务，**没有联机跑过**。第一次用先拿一条试。
