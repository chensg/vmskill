# 片型：Short 新做法（2026-11-07 起）

竖版 1080×1920，180 秒以内，外挂 SRT，中英双语。用户 2026-11-07 定的七条，
出处是「观众在看的 6 条 Short」拆片。开片：

```bash
python episode.py new <项目目录> --type short --title 片名
```

它会放好 `build/segment_config.py`（预设在 `scripts/presets/segment_config_short_v2.py`），
模板 `make_story_v.py` 不用改，只填预设里带「填」的那些。

## 七条

| | 规矩 | 落在哪 |
|---|---|---|
| 1 | 第一句就抛结局或最强的事实，再倒叙 | 讲述稿 |
| 2 | 第 0 秒开口；砍句间停顿，人声占全片 ≥ 90%（语速不变，片长随之缩短） | `TIGHT_PACING` + 四个气口值 |
| 3 | 画面顶部常驻两行标题条 | `TOP_BAR` |
| 4 | 5~7 秒换一个镜头（多出图，或一张图切远近两个景别） | `CLIPS` |
| 5 | 直接引语多给主角，而且只给主角一人 | 讲述稿 |
| 6 | 配乐更轻或不用；有配乐就切掉 150Hz 以下 | `MUSIC_GAIN` / `MUSIC_HP` |
| 7 | 收尾一句情绪总结。**不加求赞、不对观众喊话** | 讲述稿 |

## 三个旋钮是干什么的

- **`TIGHT_PACING = True`**：放行两条旧检查，「冷开场第一句要留 1.2s」（`check_coldopen`）和
  「转场要落在两句之间的静默里」。它们守的是旧节奏，和 0 秒开口、边说边切镜正面冲突。
  缺省 `False`，旧片照旧拦。
- **`TOP_BAR = dict(lines=[第一行, 第二行], y=250, gap=109, fs=(76, 62))`**：烧进画面、全片常驻。
  `y` 是第一行的中心高度，`gap` 是两行中心距，`fs` 是两行字号。第一行白字、第二行黄字，带半透明黑底。
  写法照标题：先给「N 千年前」或最强的事实，第二行给处境。
- **`MUSIC_HP = 150`**：配乐过一道 150Hz 高通。手机喇叭放不出那段低频，它只占响度。
  ⚠ 低频的大头其实是男声旁白，所以这一条效果有限，别指望靠它把人声托出来。

气口参考值（2026-11-07 四支测试片，实测人声占 88~91%）：

```
PRE_DEF, POST_DEF = 0.03, 0.08     # 句内
GAP_PRE, GAP_POST = 0.12, 0.20     # 镜间
XFADE = 0.6;  TAIL = 1.0;  FADE_IN, FADE_OUT = 0.2, 2.0
MUSIC_GAIN = -21.0
```

## 连带的几条

- **封面**：Short 只有一张，做中英双语（`COVER_TEXT` 里中英文各几行）。先挑最好看的脸或景。
- **字幕**：`SUB_MODE = "srt"`。烧录字幕和多语言音轨不能共存。
- **AI 声明**只写在简介里，不打角标（`SHOT_LABELS` 留空）。
- **画面**：古代题材人物画好看、不用藏脸；近现代真人仍然藏。第一镜是点击率，先放最好的一张。
- **片长**由 `sync` 量，不手算；`HARD_LIMIT = 180`。

## 做完怎么验

```bash
python episode.py status <项目目录>      # 各环节到哪一步了
python episode.py deliver <项目目录>     # 封装、响度、片长、字幕、英文轨、封面、发布文案、门禁；只打印没过的
```
