# 片型：横版长片，分章节＋章节卡（2026-10-21 起）

横版 1920×1080，外挂 SRT，中英双语（英文是独立音轨）。片长由故事定，不设上限，但要紧凑：每镜都要带新东西。

```bash
python episode.py new <项目目录> --type long --title 片名
```

它铺的是 `film.py` 和 `film_config.py`，不是讲述引擎。怎么做出来见 `long-film.md`；这份只讲规矩。

## 分章

- 写稿时就分章。**每章至少约 4 分钟**：20 分钟左右分 5 章，30 分钟左右分 6 章。
  两三分钟的章并进相邻章。写稿时的「幕」可以更细，但不出字卡。
- 冷开场不算一章。
- **片名卡兼作第一章的开头**，第一章不另放章节卡（两张卡紧挨着显得重复）。

## 章节卡

- 全幅背景（一段 8 秒的生成影片，或公版图慢推），压暗，正中「第 X 章　章名」。
- 停 3 秒，无旁白，淡入淡出。

## 简介里的章节时间码

- 第一条必须是 `0:00`（冷开场，照标第一章）。
- 至少 3 条，每段 ≥ 10 秒，按**实际成片**的时间码填。中文简介和英文简介各一份。
- `episode.py deliver` 会验这四条。

## 默认不放的

对观众说话的东西：开场提问、订阅口播、频道卡。用户说的是「先去掉」，**要放先问**。

## 讲法

- 要故事，不要流水账。连续几条「某年某事」合成一场来讲；时长不重要。
- 引语只给主角一人；旁白里的「他」只指主角，换了人再回到主角时用名字。
- 引诗要少：只留有名、应景的，一首一联；稍有难度就跟一句白话。

## 怎么做出来

走 `film.py`，见 `long-film.md`。章节卡、片名卡、档案页点亮字行、地图画路线都在它里面，写进 `film_config.py` 的 `SPEC` / `CARD_BG` 就行，不用每支再写一套。

早先两支（《季子平安否》《海圖上找不到的島》）走的是讲述引擎：一章一段、`make_story_h.py` 渲段、`join.py` 拼全片，章节卡先做成短片当一个无旁白的镜。那条路还能用，但成镜工具是那两支自己写的，没收进技能。

响度：`film.py` 混完整片归一到 −15 LUFS。《剩人》是收进来之前做的，按旁白 −16、没有整片归一，量出来 −16.2，`episode.py deliver` 会报。
