# 片型：横版长片，分章节＋章节卡（2026-10-21 起）

横版 1920×1080，外挂 SRT，中英双语（英文是独立音轨）。片长由故事定，不设上限，但要紧凑：每镜都要带新东西。

```bash
python episode.py new <项目目录> --type long --title 片名
```

长片**没有 `segment_config` 预设**。原因写在最后一节。

## 分章

- 写稿时就分章。**每章至少约 4 分钟**：20 分钟左右分 5 章，30 分钟左右分 6 章。
  两三分钟的章并进相邻章。写稿时的「幕」可以更细，但不出字卡。
- 冷开场不算一章。
- **片名卡兼作第一章的开头**，第一章不另放章节卡（两张卡紧挨着显得重复）。

## 章节卡

- 全幅背景（一段 8 秒的生成影片，或公版图慢推），压暗，正中「第 X 章　章名」。
- 停 3 秒，无旁白，淡入淡出。

## 简介里的章节时间码

- 第一条必须是 `0:00`（冷开场，照标第一章）。
- 至少 3 条，每段 ≥ 10 秒，按**实际成片**的时间码填。中文简介和英文简介各一份。
- `episode.py deliver` 会验这四条。

## 默认不放的

对观众说话的东西：开场提问、订阅口播、频道卡。用户说的是「先去掉」，**要放先问**。

## 讲法

- 要故事，不要流水账。连续几条「某年某事」合成一场来讲；时长不重要。
- 引语只给主角一人；旁白里的「他」只指主角，换了人再回到主角时用名字。
- 引诗要少：只留有名、应景的，一首一联；稍有难度就跟一句白话。

## 怎么做出来：现在有两条路，都还没收进技能

| | 走引擎 | 整片一个合成脚本 |
|---|---|---|
| 做过的 | 《季子平安否》《海圖上找不到的島》 | 《剩人》 |
| 结构 | 一章一段，每段一个 `segment_config.py`，`make_story_h.py` 渲段，`join.py` 拼全片 | 一个脚本从旁白、影片、外部素材直接合成全片，并导出章节时间码 |
| 章节卡 | 先做成「成镜」短片，当一个无旁白的镜放进 `CLIPS`（`video=`） | 脚本里的「卡」镜 |
| 段配置 | 由那一支自己的 `出段配置.py` 从讲述稿和镜头表生成 | 不需要 |

**章节卡、片名卡、档案页点亮字行、地图画路线、古画横移竖摇**这些成镜工具，目前是每支长片各写各的
（《季子平安否》的 `tools/make_card.py`、`make_route.py`、`page_glow.py` 等，《剩人》的 `成片_正式版.py`）。
开新长片时从上一支复制过来改，别从头写。把它们收成技能里的通用脚本是一件单独的事，还没做。

响度：技能的标准是 −15 LUFS（−14~−16）。《剩人》的合成脚本按旁白 −16 做，整片量出来 −16.2，
`deliver` 会报。新长片的合成脚本末尾加一道全片归一到 −15。
